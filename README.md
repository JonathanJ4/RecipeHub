# Recipe Hub

Recipe Hub is a React and Express recipe application backed by MongoDB.

## Current Stack

- React
- Vite
- Tailwind CSS
- Express
- MongoDB / Mongoose
- AWS S3 for recipe images

## Running Locally

### Frontend

```sh
npm install
npm run dev
```

### Backend

```sh
cd server
npm install
npm start
```

The backend requires environment variables defined in `server/.env`.

See `server/.env.example` for the required variables.

## Project Status

This project is currently being refactored and rebuilt into a voice-powered RAG cooking assistant.
